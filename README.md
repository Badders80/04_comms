# 04_comms

Communication strategy, social media campaigns, and marketing copywriting hub.

---

## Quick Start

```bash
# Install dependencies (when tools are initialized)
npm install

# Review existing content schedules and inbox drafts
cd campaigns/
```

---

## Structure

```
04_comms/
├── campaigns/    → Active social media campaigns & schedules
├── inbox/        → Draft copy, intake briefs, and story concepts
├── strategy/     → Brand voice guidelines and channel guidelines
├── MEMORY.md     → Session state and decisions
├── AGENTS.md     → Agent rules for writing and scheduling
├── HANDSHAKE.md  → API contract with 01_evolution/
├── BUILD_SUMMARY.md → What exists
└── GAME_PLAN.md  → Build plan
```
